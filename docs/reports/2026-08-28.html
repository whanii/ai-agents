Executive Read

  • AgentCore 샘플은 에이전트 실험을 프로덕션 아키텍처로 옮길 때 필요한 확장성, 안정성, 보안 패턴을 참고 구현으로 제공한다.
  • stride-gpt와 strix는 보안 검토를 설계 단계와 취약점 점검 단계에 각각 자동화하려는 흐름을 보여준다.
  • OpenMontage는 영상 제작을 다수의 파이프라인, 도구, 에이전트 스킬로 분해해 콘텐츠 운영 자동화를 실험할 수 있게 한다.
